# 遊戲操作檢查

點擊次數從該場景開始計算。「收服」等需要指定目標的能力保留選擇指令和目標兩步。提交戰鬥行動後，戰局即結算並自動存檔。

| 場景 | 操作 | 最短路徑 |
| --- | --- | --- |
| 主選單 | 新遊戲、續玩、音效開關 | 各一步。新遊戲開啟角色選擇頁，確認角色後出發。 |
| 主選單 | 讀取指定存檔 | 開欄位再選一次 |
| 主選單與暫停 | 調整音量、動畫和名稱 | 開設定再直接調整，即時保存 |
| 世界 | 戰鬥、商店、事件、月泉 | 點地標一次，自動移動並執行地標功能 |
| 世界 | 購物或取得事件獎勵 | 地標開啟後點商品或獎勵一次。購物預設裝入莉歐物品欄，換收貨者時才多一步 |
| 世界 | 選擇與瀏覽精靈 | 手冊 → 精靈兩步，檢視中前後切換各一步 |
| 精靈檢視 | 進化 | 直接點顯示進化名稱的按鈕一次 |
| 戰場 | 選隊友、移動、近戰普攻、脫離、衝刺、待機、撤回 | 各一步。普攻需有合法近戰目標 |
| 戰場 | 法術、收服 | 固定指令列選指令，再點地面或精靈，共兩步 |
| 戰場 | 看狀態、開物品欄 | 固定指令列各一步，使用物品再點一次 |
| 戰場 | 召喚 | 開召喚配置後，每隻各選名稱和落點，最後一次提交。逐一點選有助於更改位置及核對剩餘魔力。確認可用 Enter |
| 戰場 | 取消 | 短按右鍵、Esc 或點取消。拖過 6 像素才啟動鏡頭旋轉。配置召喚時第一次取消目前的精靈選擇，已配置的其他精靈保留 |
| 戰場 | 撤回移動 | 安全移動後短按右鍵或點「撤回移動」，沿原路返回並退還本步的移動距離。借機攻擊結算、換人、提交其他戰鬥行動或讀檔會結束這次撤回紀錄。 |
| 世界與戰場 | 手動存檔 | 開存檔欄位，點目標欄位。存檔即寫入，再次打開可查看 |
| 面板或章節結算 | 返回 | 右鍵、Esc、關閉鈕或點遮罩可關閉一般面板。章節結算用「返回大地圖」 |
