# 莉歐與六屬精靈造型設定

精靈設定圖採側面、正面與四分之三視角。Blender 依側面調整輪廓，參照正面調整眼距、足距和胸頸形狀。初始與進化形態各有上色定位，依地面、眼線、肩與尾尖，將毛色與鱗片色帶投影到網格頂點。

## v0.11 正側視角核對

遊戲使用同一鏡位載入新舊模型，各取正面與側面，再與設定圖比對。以下記錄實際修改及仍看得見的差異。

| 對象 | 已收斂的差異 | 仍可看見的差異 |
| --- | --- | --- |
| 莉歐 | 收窄整體身形，分出斜瀏海與臉側髮束，加長並收細魔杖，調整斗篷與交襟的下擺。 | 臉頰、鼻部和髮絲的細節仍較簡化。 |
| 泡泡龜系 | 延長側面的頸線，強化甲片隆起與層差，進化形態新增下彎喙與分叉珊瑚。 | 甲片的崩角和逐片鱗紋仍比設定圖規整。 |
| 炭炭龍系 | 收薄身體與下肢，把頸線向上拉長，進化形態分出深色背棘和熔光。 | 腳掌與後腿轉折仍比設定圖圓厚。 |
| 苔苔貓系 | 腰腹抬高，腿更細，尾端加厚，進化葉冠沿著頭部向後收。 | 毛束與條紋交界仍比設定圖柔和。 |
| 風鈴鳥系 | 收低翅根與尾角，拉長重疊飛羽及後掠冠羽。 | 胸羽的層數和尖端細節仍有差距。 |
| 電栗鼠系 | 壓低腹部、加厚後腿的外輪廓，旋轉耳廓角度，進化形態使用環耳和藍紫背晶。 | 鼠頰與胸口的細毛層次仍較少。 |
| 雪耳犬系 | 收細腳掌與腿，拉長頰鬃輪廓並縮低進化冰片。 | 蓬尾維持連續曲面，設定圖可見更多獨立毛束。 |

## v0.12 模型修訂

莉歐的頸骨移到衣領內側，臉部下緣、延伸至衣領內的喉部和辮子分別以漸變權重接到頭與軀幹。初始及進化的六系模型都重新檢視正側視角。龜甲提高甲片層差，龍系拉長吻部，貓系加深條紋並補胸毛，鳥系增加胸羽層次，鼠系補胸頰絨，犬系增加尾部毛束。模型仍有網頁用的幾何簡化，尤其是臉部與單根毛髮。

## v0.13 臉部與動畫檢查

莉歐對照設定圖的眉弓、鼻樑、嘴唇和下顎重塑。正面圖的色調按下巴、嘴唇、鼻尖及眼線分區投影到臉部。本次增加弧形漸細眉毛並降低眼白和高光亮度，仍保留網頁模型較低的面部細節。

鳥與龍的頸部有獨立骨骼與漸變權重。鳥翼和胸側改為不同的權重區域，胸廓不會被張翼拉離。貓梳理、龜縮頸、鳥理羽和數種前肢施法的動作幅度也已調整，以保留接觸處的間距。
