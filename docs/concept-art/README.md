# 六屬精靈造型設定

三張生成設定圖採側面、正面與四分之三視角。Blender 依照側面重建輪廓，參照正面調整眼距、足距和胸頸形狀，再用斜前視角確認材質分層。

| 設定圖 | Blender 模型設計 |
| --- | --- |
| [泡泡龜、炭炭龍](moon-turtle-ember-drake.webp) | 泡泡龜採低重心、寬趾、象牙色甲緣和八片隆起的青玉背甲。炭炭龍採前伸的窄吻、平衡長尾、金棕色後掠棘、獨立下顎和彎爪。 |
| [苔苔貓、風鈴鳥](moss-cat-wind-bird.webp) | 苔苔貓採骨架偏瘦的山貓身形、耳簇、頰毛和斑駁條紋。風鈴鳥的翅膀沿身側收折，飛羽交疊，腹部淺色、腿部細長，保留紫色虹膜和雙羽冠。 |
| [電栗鼠、雪耳犬](storm-mouse-frost-hound.webp) | 電栗鼠身體低圓，具有中空淡紅耳廓、暖棕毛與細長環尾。雪耳犬採深淺分界清楚的藍灰毛色、分層頸鬃和上捲的蓬尾。 |

設定圖描繪初始形態。進化形態沿用各物種的比例和材質，再加入較大的元素構造。
