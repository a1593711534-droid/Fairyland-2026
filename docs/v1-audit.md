## 驗證方式

- `npm test` 驗證移動遮擋和借機中斷、逐屬性開局召喚、批次原子性、重複與落點拒絕、撤回與收服狀態、經驗、進化、範圍法術、物品與重訪、遷移及 Blender clip。
- `npm run build` 建置正式靜態遊戲。3D 引擎延遲載入，主選單的 JavaScript gzip 約 24 KB。
- Chromium 操作測試覆蓋購買、持有裝備、地圖事件、移動取消、兩隻配置的預覽與提交、兩種情境選單、獨立物品欄、範圍預覽及讀存檔。檢查桌面與較窄橫向視窗。
- 戰術參考見 [先攻](https://bg3.wiki/wiki/Initiative)、[借機攻擊](https://bg3.wiki/wiki/Opportunity_Attacks) 與 [視線規則](https://bg3.wiki/wiki/Sight_mechanics)。
