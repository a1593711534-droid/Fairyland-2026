# 精靈幻境 2026

以 Three.js 和 Blender 製作的繁體中文 3D 無網格戰術 RPG。第一版可以玩莉歐的火系召喚師，在月見森林捕捉、召喚及進化六種精靈。

## 開始遊玩

需要 Node.js 24。

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址。遊戲需要 WebGL 2。進度存在目前瀏覽器和網站來源中，支援自動存檔與三個手動欄位。

```sh
npm test
npm run build
npm run preview
```

正式建置在 `dist/`，可以放到靜態網站。GitHub Actions 也會將建置上傳為成品。

## 第一版的遊玩路線

1. 選擇「新遊戲」和莉歐，在大地圖選「微光林地」。
2. 莉歐開局有六種屬性的精靈。進入戰鬥後可立刻召喚，也可以用「收服」再招募野生精靈。離開敵人近戰距離前，可以用主要行動「脫離」。畫面會標示射程、遮擋和命中率。
3. 召喚時請選擇莉歐法陣內的空地。召喚不花主要行動，但會扣魔力。魔力低於 5 時，場上的夥伴會脫離掌控。
4. 讓夥伴參戰並擊敗練習精靈以快速獲得經驗。回大地圖後，在精靈手冊為 Lv. 3 以上的精靈進化。
5. 在「月泉營地」整備，再挑戰有敵方召喚師的「月門遺跡」。

戰場上選擇可行動角色後，青色地面會顯示可抵達範圍。滑鼠移到地面會顯示移動路徑，紅線表示超出剩餘距離。點地面移動，拖曳右鍵旋轉鏡頭，滾輪縮放。戰鬥中 `Space` 待機，`Esc` 取消選擇或開啟選單。

## 資料與素材

- `src/game/content.js` 集中管理屬性、技能、生物、數值與關卡。 `combat.js` 處理回合、資源和狀態，`ai.js` 評估位置、射程、掩體、擊殺機率與撤退。
- `src/render/` 載入 Blender 匯出的骨架模型並播放動畫，有各屬性不同的粒子運動和收服效果。
- `public/art/` 包含遊戲使用的模型與主選單插畫。安裝 Blender 4.3 後可用 `npm run art` 重新製作骨架、造型與場景模型。
